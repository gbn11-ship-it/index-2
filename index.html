جميع الكانجي المقررة في الأسبوع الخامس مع القراءتين والمعنى

1. الكانجي: 生
المعنى: حياة / يولد / خام / طازج

القراءة الصينية (On'yomi): せい (sei) / しょう (shō)

القراءة اليابانية (Kun'yomi): い / う / なま (i / u / nama)

أمثلة معتمدة:
• 先生 (せんせい - sensei): معلم
• 生まれます (うまれます - umaremasu): يولد
2. الكانجي: 五
المعنى: الرقم خمسة (5)

القراءة الصينية (On'yomi): ご (go)

القراءة اليابانية (Kun'yomi): いつ (itsu)

أمثلة معتمدة:
• 五人 (ごにん - gonin): خمسة أشخاص
• 五月 (ごがつ - gogatsu): شهر مايو
3. الكانجي: 間
المعنى: مدة / فترة / بين / مسافة

القراءة الصينية (On'yomi): かん (kan) / けん (ken)

القراءة اليابانية (Kun'yomi): あいだ (aida) / ま (ma)

أمثلة معتمدة:
• 時間 (じかん - jikan): وقت / مدة
• 週間 (しゅうかん - shūkan): أسابيع
4. الكانجي: 上
المعنى: فوق / أعلى / يرفع

القراءة الصينية (On'yomi): じょう (jō)

القراءة اليابانية (Kun'yomi): うえ (ue) / あ (a) / のぼ (nobo)

أمثلة معتمدة:
• 上 (うえ - ue): فوق / أعلى
• 上手 (じょうず - jōzu): ماهر / بارع

شرح قواعد الأسبوع الخامس الكاملة والتطبيقات عليها

📌 القاعدة 1: تحويل أفعال المجموعة الأولى (أفعال る) إلى صيغة て (Te-form)

الشرح: أفعال المجموعة الأولى (أفعال Ru) أفعال بسيطة جداً، تحول حذف الحرف الأخيرة る وتنصيب الحرف て مباشرة مكانها.
القاعدة: نحذف る ونضيف て.
أمثلة:
• たべる ← たべて (يأكل)
• みる ← みて (يرى)
• おきる ← おきて (يستيقظ)
• おしえる ← おしえて (يعلّم)

📌 القاعدة 2: تحويل أفعال المجموعة الثانية (أفعال う) إلى صيغة て

الشرح: يعتمد التحويل على الحرف/المقطع الأخير في جذر الفعل كالتالي:
• く ← いて (مثال: かく ← かいて)
• ぐ ← いで (مثال: およぐ ← およいで)
• す ← して (مثال: はなす ← はなして)
• つ / る / う ← って (مثال: まつ ← まって / かえる ← かえって / かう ← かって)
• む / ぬ / ぶ ← んで (مثال: のむ ← のんで)
🚨 استثناء شاذ مهم: الفعل いく (يذهب) يصبح いって وليس いいて.

📌 القاعدة 3: الطلب والأمر المهذب (صيغة て + ください)

الشرح: نستخدم صيغة て متبوعة بـ ください للتعبير عن "من فضلك افعل كذا".
أمثلة رسمية:
• ちょっと まってください (من فضلك انتظر لحظة)
• ゆっくり はなしてください (من فضلك تحدث ببطء)
ملاحظة للمقربين (غير رسمي): نحذف ください فقط (مثال: ちょっとまって).

📌 القاعدة 4: الفعل المستمر والحالة المستمرة (صيغة て + いる / います)

الشرح والتكوين: صيغة て + いる (أو います للتشريف/الرسمي) تعبر عن:
1. فعل جارٍ الآن: いま ごはんを たべています (أنا أتناول الطعام الآن).
2. حالة مستمرة ناتجة عن فعل: かれは とうきょうに すんでいます (هو يسكن في طوكيو).
